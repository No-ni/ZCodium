# 回归测试入口可靠性

- 诊断回归入口只引用仓库当前存在的测试；删除的功能测试不能继续被导入，也不恢复已经移除的功能。
- CI 的无隔离外层 runner 必须等待全部诊断测试结束；子进程清除 NODE_TEST_CONTEXT，使用显式源码 tsconfig，测试文件缺失或任何测试失败都使外层失败。
- 对每个声明的测试文件校验实际执行结果，禁止仅执行前一组就报告成功。
- Windows 下动态导入本机模块必须使用 file URL，保持 macOS/CI 相同的图标验证内容。
- 验收包括：诊断测试全部执行、无隔离入口执行、缺文件/失败回归的失败传播，以及 Windows 推荐图标原有测试通过。
