# 全仓审查覆盖证据

本目录保存 2026-11-06 两轮审查的精简相对路径证据。`coverage.json` 合并各组的模块与 policy roots 覆盖；`root.json`、`backend.json`、`ui.json`、`cli.json` 列出实际阅读的契约、入口和关键实现；`structure.json` 保存最终源码数量及 AST 检查结果。

模块覆盖、机械结构扫描、选定路径的语义阅读和运行回归是不同证据。这里不宣称每个叶文件逐行人工审查、全分支运行或全平台验收；各项修复、实际验证和限制见 [总报告](../full-code-audit.md) 及四份分区报告。

完整库存、源码扫描、一次性审查脚本与本机工具链配置保留在被忽略的 `.audit/full-code`；合成测试数据和日志保留在被忽略的 `.run-logs/project-only-validation`。精简摘要不复制源码，也不包含本机绝对路径、用户数据或凭据。日志标签只用于对应本次本机记录，不表示其他机器可以直接复用。
