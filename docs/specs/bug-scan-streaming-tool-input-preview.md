# 流式工具 JSON 预览的字段边界与扫描预算

## 问题与规则

`buildZCodeStreamingToolInputPreview` 在完整 JSON 无法解析时，按 24 个允许字段逐次运行整段正则，再逐字拼接命中的字符串。这会重复扫描较大的 Write/Edit 输入；正则还会把嵌套对象中的路径当作顶层工具参数，漏掉合法的转义字段名，并在重复字段和字面 `\\u12` 尾部产生与完整 JSON 不一致的预览。

不完整输入只预览顶层 JSON object 中现有白名单的 string 字段。跳过未知值、嵌套 object/array 及字符串内部的字段样式文本；字段名遵循 JSON 转义。重复字段与完整 JSON 一致，已出现的较后值覆盖较前值，较后非 string 值移除旧 string 预览。未闭合字符串可预览其已完整到达的字符；只丢弃真正悬空的转义，不丢弃已转义的字面反斜杠或 `u` 文本。

完整 JSON 和显式 `completeInput` 仍通过既有入口返回完整值。只改纯投影，不改原始 input、白名单、节流时间、工具权限、持久化或执行行为。

## 所有者、路径与性能边界

streaming input state 仍由原调用者持有；共享工具只同步派生预览。未知/不完整结构不抛业务错误，保留已确认顶层字段或返回空预览。不新增缓存、计时器或跨进程状态。

```text
原 runtime input delta → 原 rawInput state
  → 既有 materialize 节流 → 共享 JSON 预览
      → 完整 JSON 原值 / 不完整 object 的一次顶层扫描
  → 原 Desktop continuous 或手机 replayable 投影
```

一次预览不得为每个候选字段对整段 rawInput 运行正则。用单次词法扫描界定字段和值，字符串直接切片后解码；空间随输出字段与实际字符串内容增长，不随白名单数量重复分配。

## 验收

先补失败回归：嵌套字段不外溢、顶层 array 不冒充 object、转义字段名、重复字段、非 string 覆盖、字面 `\\u12` 的半截尾部，以及大输入的整段正则扫描预算。覆盖有效完整输入、显式完成值、各种白名单字段、嵌套未知值后的顶层字段、转义引号/换行/反斜杠和真正悬空转义。

回归纯内存执行，通过项目内隔离 runner 保存结果。记录整段正则调用数和观测时间；时间不设 CI 阈值，也不宣称真实模型或 UI 真机吞吐。

实际验证（Node 24.14.0）：修改前 48 项中 10 项失败；修改后 48 项通过。560,046 字符夹具的整段正则调用由 24 次降为 0 次；单次观测约 50.48 ms → 5.62 ms，仅为同环境观察，不作稳定性能保证。未调用真实模型或进行 Electron 整机验收。
